## 📌 Sobre o Projeto

O projeto consiste no desenvolvimento de um site de uma imobiliária, criado para apresentar um imóvel residencial disponível para venda.

O objetivo é disponibilizar de forma simples e organizada as principais informações do imóvel, como características, fotos, localização, valor e formas de contato.

---

- CSS3

## 🎯 Objetivo

Aplicar os conhecimentos adquiridos durante as aulas de Desenvolvimento Web na criação de um site funcional, organizado e com uma navegação simples para o usuário.
