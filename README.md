## 📌 Sobre o Projeto

O projeto consiste no desenvolvimento de um site para divulgação de um imóvel residencial disponível para venda.

O site foi criado com o objetivo de apresentar as principais informações da casa, como características, localização, valor, ambientes, área construída e formas de contato, proporcionando uma navegação simples e fácil para o usuário.

---

## 🏡 Imóvel

O imóvel apresentado está localizado no bairro **Vila Piloto, em Três Lagoas/MS**, próximo à Delegacia da Polícia Civil e ao CRAS.

### Principais características:

- Terreno de **300 m²**
- **201 m² de área construída**
- **170 m² de laje**
- 3 quartos, sendo 1 suíte
- Sala ampla com pé-direito alto
- Cozinha interna
- Banheiro social
- Lavanderia
- Garagem coberta
- Energia solar fotovoltaica
- Área gourmet com churrasqueira
- Edícula com cozinha integrada
- Sistema de câmeras
- Cerca elétrica
- Concertina

### 💰 Valor

**De R$ 420.000 por R$ 400.000**

O imóvel também **aceita financiamento**.
